File description:

The “India Housing Prices” dataset contains 2.5 lakhs rows and 23 columns, offering detailed insights into housing market trends across various Indian states. It includes attributes related to - property types, pricing, location, and amenities, making it suitable for analysis ranging from basic descriptive statistics to advanced machine learning applications.

Columns in our dataset:

Some preliminary observations of the given dataset:

  • ID: Different rows having different Integer values.

  • State: Indian States ( character ).

  • City: Name of Cities ( character ).

  • Locality: Name of Localities ( character ).

  • Property_Type: There are 3 types of properties - Apartment, Independent House, Villa ( character ).

  • BHK: 5 varieties are there - 1,2,3,4,5 ( integer ).

  • Size_in_sqFt: Plot size in Sqft ( integer ).

  • Price_in_Lakhs: Price of the properties in Lakhs ( Double ).

  • Price_per_SqFt: Price of the properties per Sqft ( Double ).

  • Year_Built: Year in which the property was built ( integer ).

  • Furnished_Status: Status of furnishing - Furnished, Unfurnished, Semi-furnished ( character ).

  • Floor_No.: Floor No. ( Integer ).

  • Total_Floors: Total no. of floors ( Integer ).

  • Age_of_Property: Age of the property ( Integer ).

  • Nearby_Schools: No. of schools nearby ( Integer ).

  • Nearby_Hospitals: No. of hospitals nearby ( Integer ).

  • Public_Transport_Accessibility: Ease of accessing public transportation - High, Low, Medium ( character ).

  • Parking_Space: Availability of Parking space - Yes, No ( character ).

  • Security: Proper security system - Yes, No ( character ).

  • Amenities: Amenities like: Playground, Gym, Pool, etc. ( character ).

  • Facing: Orientation of the house - East, West, South, North ( character ).

  • Owner_Type: Type of owner - Owner, Builder, Broker ( character ).

  • Availability_Status: Status of availability - Ready_to_move, Under_construction ( character ).

calculate_premium <- function(amenity_name) {
  # Mean price with the amenity
  mean_with <- mean(dt_expanded$Price_in_Lakhs[dt_expanded[[amenity_name]] == 1], na.rm = TRUE)
  
  # Mean price without the amenity
  mean_without <- mean(dt_expanded$Price_in_Lakhs[dt_expanded[[amenity_name]] == 0], na.rm = TRUE)
  
  # Calculate Premium
  premium_val <- mean_with - mean_without
  premium_pct <- (premium_val / mean_without) * 100
  
  
  data.frame(
    Amenity = amenity_name,
    Avg_Price_With = round(mean_with, 2),
    Avg_Price_Without = round(mean_without, 2),
    Premium_Lakhs = round(premium_val, 2),
    Premium_Percent = round(premium_pct, 2)
  )
}

Random Forest

  • Since our RMSE and MAE results revealed that luxury outliers and non-linear patterns are challenging for our LM and GLM, a Random Forest is the natural evolution for our project. It builds hundreds of decision trees and averages them, which should significantly reduce the high errors.
